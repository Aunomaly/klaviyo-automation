# Figma Design Prompts for Verniqo

Use these prompts in Claude Code to generate actual Figma designs.

---

## Welcome Email

Generate an email template design for "Welcome Email #1" with the following specifications:

**Brand:** Verniqo
**Colors:** Primary #25282A, Secondary #6B7280
**Font:** Instrument Serif
**Logo:** https://verniqo.com/cdn/shop/files/Add_a_heading_-_2025-09-19T005401.316.png?v=1758257736&width=1200

**Layout:** 600px wide for email compatibility

**Sections:**
1. **Header** (80px): Dark background (#25282A) with centered logo
2. **Hero** (300px): "Welcome to Verniqo" headline, subtext "Discover wellness through innovation"
3. **Content** (200px): Brief brand introduction, 2-3 sentences about the brand mission
4. **CTA** (120px): "Shop Now" button with secondary color (#6B7280)
5. **Footer** (100px): Social links, contact info, unsubscribe link

**Design Style:**
- Clean, modern, minimal aesthetic
- Email-safe fonts (fallback to web-safe fonts)
- High contrast for readability
- Mobile-responsive layout
- Professional wellness brand feel

**File:** Create in a new Figma file named "Verniqo - Email Templates"

## Abandoned Cart Email

Generate an email template design for "Abandoned Cart #1" with the following specifications:

**Brand:** Verniqo
**Colors:** Primary #25282A, Secondary #6B7280
**Font:** Instrument Serif

**Layout:** 600px wide

**Sections:**
1. **Header** (80px): Dark background with logo
2. **Hero** (250px): "You left something behind" headline, product image placeholder
3. **Product Details** (200px): Product name, price, brief description
4. **CTA** (120px): "Complete Your Purchase" button (prominent)
5. **Urgency** (80px): "Items in your cart are limited" message
6. **Footer** (100px): Social links, contact

**Design Style:**
- Create urgency without being pushy
- Emphasize the product with large image area
- Clear, prominent CTA button
- Professional and trustworthy tone

**File:** Add to the "Verniqo - Email Templates" file

---

## Instructions for Claude Code:

1. Copy one of the prompts above
2. Paste into Claude Code
3. Add: "Use the Figma MCP generate_figma_design tool to create this"
4. Claude Code will generate the actual Figma file
5. Copy the Figma file URL
6. Go back to the Klaviyo Automation dashboard
7. Navigate to Designs tab
8. Click on the design
9. Paste the Figma URL to link it

---

## Alternative: Browser-Based Flow

If you don't have Claude Code, you can:
1. Use Claude.ai with the remote Figma MCP server
2. Follow the same prompts
3. Generate designs directly in your browser
